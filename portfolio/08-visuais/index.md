## Recomposição visual recomendada

Para apresentação, a sequência ideal é:

1. contexto
2. processo atual
3. jornada
4. lineage
5. falha
6. solução
7. future state

Esses elementos juntos dão ao portfólio uma leitura clara, profissional e fácil de seguir.
