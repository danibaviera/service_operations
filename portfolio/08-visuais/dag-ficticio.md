# DAG fictício para portfólio

Este visual foi criado como uma representação ficcional de dependências entre repositórios do ecossistema Aurora Grid, com foco em narrativa de portfolio e não em arquitetura real.

## Objetivo

- mostrar relações produtor → consumidor de forma visual;
- ilustrar uma cadeia de dados sem expor infraestrutura real;
- reforçar o argumento de que o problema é a visibilidade das dependências e do impacto operacional.

## Como interpretar

- os quadrados azuis representam repositórios/fluxos de ingestão ou processamento;
- os círculos dourados representam armazenamento ou camada de dados;
- as linhas contínuas indicam fluxo principal de produção;
- as linhas tracejadas sugerem recepção, alerta, integração ou dependência complementar.
