# 04 -Current-State Process

## Happy Path

```text
INÍCIO
  ↓
Acessar sistema
  ↓
Consultar indicadores
  ↓
Validar informações
  ↓
Realizar análise
  ↓
Executar atividade
  ↓
Compartilhar resultado
  ↓
FIM
```

## Exception Path

```text
Consultar indicador
       ↓
Está disponível?
   ↙         ↘
 SIM         NÃO
 ↓            ↓
Analisar    Procurar informação
              ↓
           Consultar sistemas
              ↓
           Perguntar para equipe
              ↓
           Identificar responsável
              ↓
           Investigar problema
              ↓
           Aguardar resolução
              ↓
           Validar dado
              ↓
           Retomar atividade
```

## Insight

O processo esperado é simples. A complexidade aparece quando existe uma exceção. Isso é uma oportunidade importante para mostrar que a dor não está na operação em si, mas na perda de visibilidade do fluxo de dados.
